Quick facts for the agent

  • Local PDF editor (annotate, forms, OCR, project save).
  • Default launch: **Open GA PDF Editor.url** → http://127.0.0.1:17880 (SVC).
  • Documents are not uploaded to a remote app server.
  • Editor workspace = annotations; Form workspace = design fillable fields (M toggles).

Intake questions

  1. How did they launch? (.url / PWA / index.html / intranet URL)
  2. Slim package ever run Setup? Any missing-library errors?
  3. File type: PDF vs .gapdf project?
  4. Symptom: open, edit, save, export, forms, OCR, password, print?
  5. Browser + version; any recent Windows/AV update?

Common issues

App won’t open / blank page

Check Action
SVC running? Start GA-PDF-Editor-SVC.exe from install root
Port busy? Read MessageBox / free port or set GAPDF_SVC_PORT and update .url / reinstall PWA
Slim without setup Run Setup.bat once with network
Stale cache Hard refresh; confirm app/config.js version string after upgrades

“Libraries missing” / OCR / password fail

  • Re-run setup or deploy full package.
  • file:// needs embed bundles generated by setup; prefer SVC HTTP origin.

Can’t edit shapes / text

  • Confirm Editor workspace (not Form).
  • Tool mode not stuck on form tools; press Esc-friendly clear or choose Pointer.

Forms missing after export

  • Design fields in Form workspace; export fillable PDF path (not “print to PDF” from OS).
  • Re-open export in a second viewer to verify AcroForm widgets.

Session tabs empty after reboot

  • Feature flag / IndexedDB cleared / browser site data wiped.
  • User may have opened via different origin (port changed → different origin).

PWA opens wrong/old port

  • Sticky port: restore previous .url or reinstall PWA after intentional port move.

Performance / large PDFs

  • Huge scans: lower zoom; close extra tabs; OCR only on active tab.
  • Session byte cache may skip very large files (maxSessionPdfBytes).

Safe recovery steps (order)

  1. Reproduce with a small non-sensitive PDF.
  2. Restart SVC; reopen .url.
  3. Different browser profile / InPrivate (rules out extension interference).
  4. Clear site data for the app origin only if user accepts losing session restore.
  5. Reinstall same version to a clean folder; do not delete user project files.

What support should not do

  • Promise “certified redaction” from the thick line tool.
  • Collect production PDFs with regulated data into personal email without policy cover.
  • Change config.js feature flags globally without change control.
