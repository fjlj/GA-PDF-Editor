GA PDF Editor:
how I accidentally built a PDF workstation in the browser

GA PDF Editor is an offline-first PDF workstation that runs in the browser: annotate, fill and design AcroForms, run local OCR, save projects, and export honest PDFs — all as static files, no server round-trip required for the document itself. Offline matters because your document bytes stay on the machine: open from a USB stick or localhost, work without a cloud account, and never upload sensitive PDFs “just to edit them.”

Hi. Short field journal this time — multi-tabs, dual form layers, instruction-tape undo, export that doesn’t lie, and a zip so small it feels like a prank. Grab tea. There will be AcroForms. There will be feelings. There may be a missing semicolon.

1. What even is this thing

Not “I put a PDF on a canvas and shipped it.” A little desktop-class PDF workstation that still ships as boring static files — scribble, fill, design fields, OCR, project save, export Adobe won’t laugh at — without yeeting documents into the cloud.

What it is ♥

  • Client-side viewer/editor for PDF people
  • Editor (fill + annotate) vs Forms (design fields)
  • Multi-doc tabs · .gapdf projects · honest final PDFs
  • Offline-first, vendored deps — USB stick energy

What it is not

  • Not a cloud DMS / real-time collab suite
  • Not a courtroom e-sign identity circus
  • Not a React/Vue SPA with a webpack novel
  • Not “flatten to image and hope”
Whiteboard rules (and the tears under them)
  • No bundler — config.js load order + ?v= cache-bust. Old school. Kind of proud.
  • Offline / USB / file:// — OCR and password-protect when Wi‑Fi is a myth.
  • Privacy — bytes stay on the machine. No “upload for processing” side quest.
  • Honest export — annotations can flatten; form fields stay fillable AcroForms.
  • Operator reality — ship without installing Node on every desk like a lifestyle brand.

2. Feature menu (the world is your oyster… or clam)

For S’s and G’s: a tidy inventory of what the workstation actually does. Combine PDFs for free. Drag pages around. Design fillables. OCR a scan. No cloud upsell, no “three free merges then please subscribe.” The world is your oyster — or clam, or whichever bivalve you’re comfortable shipping on a USB stick.

Documents & pages

  • Open / append PDFs and .gapdf projects (multi-select OK)
  • Combine PDFs for free — merge many files into one document (or open each as its own tab)
  • Insert PDF mid-stack from the Pages panel (green button energy)
  • Reorder pages with drag-and-drop on thumbnails (undoable)
  • Delete pages with the × on a thumb
  • Rename pages — double-click the thumb label
  • Multi-document tabs — each keeps its own zoom, overlays, and history
  • Session restore — handles + PDF bytes in IndexedDB after a refresh
  • Drag-and-drop files onto the window to open or append

Annotate & layout

  • Add text overlays (sticky-note vibes welcome)
  • Edit / stamp rich text blocks with fill & border
  • Shapes — rectangle; line / quick redaction bar
  • Tables / grids with live controls
  • Insert images and position them on the page
  • Snip & move — cut a region and place it elsewhere
  • Signatures — type a name, pick a cursive style, stamp it
  • Drag, resize, rotate, snap guides, multi-select marquee
  • Toggle render smoothing when the pixels get opinions

Fillable forms (AcroForms)

  • Editor mode — fill existing native form fields
  • Forms mode — design / move / multi-select field shells
  • Field types: text, checkbox, radio, dropdown, signature
  • Auto-import natives into designer twins when you open a fillable PDF
  • Dropdown option editor for list choices
  • Honest export — re-embeds real widgets at designer geometry (still fillable later)

OCR, print & open

  • Scan OCR (Tesseract, offline English) — active tab only
  • Works on file:// via base64 embeds after setup
  • Hold Shift to force a re-scan when the goblins demand it
  • Print flattened page images with orientation-aware CSS
  • Open password-protected PDFs (unlock dialog)
  • Zoom in / out; keyboard shortcuts help modal (?)

History & trust

  • Undo / redo — instruction-tape command history (not haunted closures)
  • History panel lists macros you can actually read
  • Page moves, deletes, renames, and overlay edits participate in the tape
  • Project audit breadcrumbs ride along in .gapdf saves

Save, protect & ship

  • Save Project (.gapdf) — real PDF + gzip JSON trailer (overlays, form state)
  • Save PDF — flatten annotations; keep fields fillable; quality presets (draft → ultra)
  • Password-protect on export (QPDF WASM / AES) without murdering fillables
  • Offline-first: static files, USB-friendly slim zip + Setup.bat
  • Optional local SVC + PWA install on sticky localhost (no admin)
  • Close / Close All when you’re done being productive
Free as in “we don’t meter merges.” Combine, reorder, delete, annotate, form-design, OCR, encrypt — all client-side. Your document bytes stay on the machine. The clam stays closed to the cloud.

7. Boss fights

Several of these bugs had my full name in the stack trace. Expand only the trauma you need.

All collapsed by default — skimmers stay free.

Boss Multi-tab event isolation

Tools only worked on tab one. Listeners bound once to the original #viewer; new panes never got the memo. Tab 2: beautiful. Also: mute.

Lesson: bind high, resolve the live pane — preferably before demo day.

Boss Dual form layers having a knife fight

PDF.js paints interactive AcroForms; designers need movable shells. Hide natives too hard → fill vanishes. Leave both → double fields and the legendary “flash then gone.”

Lesson: two jobs, two modes (Editor fill vs Forms design) — not one boolean named formsAreOnIGuess.

Boss Delete means delete (please)

copyPages brings page /Widget annots even when the high-level form API looks empty. Deleted fields paid rent and came back.

Lesson: strip at the page Annots level. form.removeField() alone is a polite suggestion.

Boss Create ≠ “a human can click this” 
[embedAllFormFields] wrote widgets= 0 failed= 4 form.getFields()= 4

Four fields on the AcroForm object. Zero page widgets. Usually addToPage threw after createTextField already “succeeded.” Bonus: strip catalog /AcroForm while the private form cache still hugs an orphan.

Lesson: count widgets on pages. Fresh form after strip. Never pass NaN geometry to a library that believes you.

Boss Races dressed as flaky features

Project restore via setTimeout(100), global getElementById across tabs, import gated on annotation CSS that hadn’t painted. Symptom: “works… unless you refresh. Or breathe wrong.”

Lesson: await render. Scope queries. Sleep is not a dependency.

Boss Offline reality vs npm daydreams

Tesseract and QPDF want workers/WASM. file:// laughs at fetch. One CDN’s DNS ghosted mid-setup. Our “custom” qpdf was a normal npm package in a trench coat (SHA matched; I felt both smart and scammed).

Lesson: base64 embeds, multi-mirror setup, never marry one CDN.

Boss PWA origin is a pinky promise

Installed PWA = married to http://127.0.0.1:PORT. Silently hopping ports orphans the install. Auto-opening a browser at logon makes users think malware invented a PDF editor.

Lesson: sticky port from the .url; MessageBox if busy; boot stays quiet. Be boring. Be loved.

8. Deeper cuts (optional lore)

Tricks, form lifecycle, and the instruction tape — still here for archaeology, not required for the tour.

Spellbook · tricks & slightly cursed spells
  • Workspace-root event delegation — every tab hears marquee/tools/wheel.
  • body.capture-safe — export/print don’t bake Form-mode dimming into pixels forever.
  • KISS embed path — snapshot → strip → new AcroForm → write. Flat field names; ga_ prefix against zombie names.
  • Macro-only history commits — mouseup / blur / coalesced arrow nudges. Undo is math on data.
  • Base64 *.embed.js — workers/WASM/traineddata that work on file://.
  • Sticky port + named mutex — single SVC instance; PWA origin stays put.

Tattoo this: “visible in the editor” must mean “serializable from the DOM.” If export can’t see shells, pdf-lib cannot telepathically invent them.

Deep dive · instruction-tape history

Early me loved { undo, redo } closures. They captured live elements, refused to serialize, and fought multi-tab restore like cats in a bag.

GaProcessor: opcode + payload. Undo inverts. Redo replays. Command pattern wearing a hoodie.

  • CREATE_NODE / DELETE_NODE · COMMIT_TRANSFORM(S)
  • SET_STYLE / SET_INNER_HTML / SET_TEXT_STATE
  • COMPOUND · LEGACY_CLOSURE (escape hatch; console side-eyes you)

House rule: no instructions on mousemove. The tape stays readable.

9. Shipping tiny zips & the little service

Slim package (~0.3 MB)

  • App source, icons, SVC.exe, Setup.bat
  • Stub lib/* + empty fonts
  • tools/setup.ps1 + manifest + this rant

One-time setup pulls vendors (multi-CDN), fonts, file:// embeds; optional start-on-boot. No Node on every desk.

GA-PDF-Editor-SVC.exe

  • mongoose on 127.0.0.1 only — stable PWA origin
  • Default port 17880; sticky from .url
  • Single-instance mutex; no auto-browser at login
  • Busy port → MessageBox, not silent betrayal
  • chdir to EXE dir so Startup finds ./app
Admin myth, busted: high port on localhost does not need elevation. User Startup / HKCU\...\Run are non-admin too. If setup asks for UAC just for this, someone wrote the wrong script.

10. Things I learned the hard way

  1. Two sources of truth need a handshake. DOM and PDF dicts drift. Export is a ceremony, not a side effect of “eh, save.”
  2. Library APIs lie by omission. “Fields length is 4” ≠ “four widgets a human can click.” Measure the file people open.
  3. Races dress up as flaky features. Hard-refresh bugs are usually ordering bugs. Await + repair > sleep + hope.
  4. Offline is a product feature, not a deploy accident. Embeds, slim packages, multi-mirror setup — design them or they design your weekend.
  5. Write the war stories down. Changelogs in dev/ exist so the next person doesn’t re-learn stencil pointer-events from first principles.
Programming rites of passage (this codebase edition)
  • Spent twenty minutes hunting a missing semicolon that turned out to be a trailing comma in a JSON-shaped object, which is just a semicolon wearing a trench coat and a fake mustache.
  • Declared victory, then learned the browser was still serving 2019 from cache. Hard refresh fixed it harder. ?v= is a lifestyle.
  • Off-by-one in a page index; the blank page was technically correct and spiritually wrong.
  • pointer-events: none on the thing you then try to drag — gaslighting yourself with CSS.
  • Commit message fix, then fix 2, then please, then a real message after shame.
  • “Works on my machine” where “my machine” means one tab, one PDF, and a full moon.

Bottom line

You can shove a static, offline-capable web app surprisingly far toward “real PDF software” — if you respect PDF structure, treat the DOM as an editor canvas with an honest export step, and treat packaging like part of the product. The hard parts were never “draw a box.” They were truth, timing, and transport.
